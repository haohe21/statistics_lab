# 抽样分布与参数估计实验室

这是配套《心理统计》参数估计章节的交互式教学程序。学生可以操纵总体均值、总体标准差、样本量 `n`、重复抽样次数 `B`、总体分布和置信水平，观察：

- 总体分布、一次样本、样本均值抽样分布；
- 理论标准误 `σ/√n` 与模拟标准误；
- 置信区间覆盖率；
- 数据库行数、独立单位、聚类/重复测量与有效样本量。
- 估计量的无偏性、有效性和一致性：分别观察重复估计的中心、分布宽度以及样本量增大后的误差收缩。

可选总体分布包括正态、右偏、厚尾、双峰、T、泊松、均匀和卡方分布。为便于比较，所有分布最后都会映射到当前设置的总体均值 `μ` 和标准差 `σ`。T 分布和卡方分布固定 `df=5`；泊松分布固定 `λ=10` 后再标准化，因此界面中的 `μ`、`σ` 仍可独立调节，离散台阶或右偏形状仍会保留。

## 图形显示说明

- 绘图已配置中文字体（Microsoft YaHei / Noto Sans SC 等候选字体），用于避免中文标题和坐标轴显示为方框或乱码。
- 三幅分布图使用共同的固定参考横轴（以总体标准差 σ=10 为参考），因此改变 σ 时，分布宽度会直观变化。
- 置信区间页同时显示当前置信区间和 90%、95%、99% 的理论区间半宽对照图；置信水平越高，临界值越大，区间越宽。

## 运行方法

这里是“两种情况”，不是每次都要连续输入三条命令：

1. **首次使用**：安装依赖，只需执行一次。
2. **以后每次使用**：直接启动程序。

在本文件所在目录打开 PowerShell 后执行：

```powershell
# 首次使用时执行一次
py -3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements_sampling_lab.txt

# 每次启动程序时执行
py -3 -m streamlit run sampling_lab.py
```

浏览器打开 Streamlit 显示的本地地址，通常是 `http://localhost:8501`。

也可以双击同目录下的 `启动抽样分布实验室.bat`。如果浏览器没有自动打开，请手动访问 `http://localhost:8501`；关闭启动窗口即可停止程序。

## 三天内的课堂用法

1. 第一课时只使用“抽样分布实验”：固定其他参数，每次只改变一个参数。
2. 第二课时使用“置信区间覆盖”：让学生先预测覆盖率，再运行模拟。
3. 第三课时使用“数据库视角”：比较数据库行数与独立单位数。

### “数据库视角”操作顺序

1. 先选“独立个体”。此时程序固定每个独立单位只有 1 行、`ρ=0`，作为基准：数据库行数、独立单位数和有效样本量相同，两种标准误计算应基本一致。
2. 再选“重复测量：每人多次”或“聚类数据：每组多人”。把“每个独立单位的记录数”调大，再逐步提高 `ρ`。
3. 观察数据库行数可能继续增加，但设计效应上升、有效样本量增长变慢，“考虑相关结构”的标准误高于“把每行当独立”的标准误。
4. 课堂讨论重点是：`m`（每单位记录数）和 `ρ`（单位内相关程度）共同决定重复记录提供了多少独立信息；重复测量与聚类的数学近似相同，但研究对象和正式分析模型不同。

### “估计量三性质”操作顺序

1. 在“⑤ 估计量三性质”中，先固定总体分布、`μ`、`σ` 和 `n`，观察左图：样本均值的重复估计中心接近真实 `μ`，而“样本均值 + 0.5σ”是故意加入系统偏移的有偏估计量。
2. 看中图：单个观测 `X₁` 与样本均值都以 `μ` 为中心（无偏），但样本均值分布更窄，说明在这两个无偏估计量中它更有效。
3. 看右图：程序固定比较 `n=2、8、32、128`。随着 `n` 增大，样本均值的误差箱线图向 0 收缩，这正是“一致性”的直观表现。
4. 改变总体分布或重复次数 `B`，让学生区分：一次样本不能证明无偏；有限模拟中中心不会恰好等于 `μ`；有效性必须在无偏（或同等目标）估计量之间比较。

## 注意事项

- 这是教学模拟，不是正式统计分析软件。
- “数据库视角”中的设计效应是近似教学公式；正式研究应使用与研究设计匹配的模型。
- 如果本机无法安装依赖，可在 RStudio 中运行同样的模拟逻辑，但本版本优先保证 Python 单文件启动。
